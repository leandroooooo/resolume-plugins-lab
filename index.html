OMT Receiver

Receba no Resolume Arena o sinal de vídeo enviado por um transmissor compatível com OMT, como o emissor do vMix. O plugin funciona como uma fonte (Source) independente.

Ver projeto no GitHub ↗ Código-fonte

Projeto funcional, testado no Resolume Arena 7.22. Consulte o repositório para os arquivos e instruções de compilação.

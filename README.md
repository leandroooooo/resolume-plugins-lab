# Resolume Plugins Lab

Site estático bilíngue (português/inglês) para apresentar plugins e ferramentas gratuitas para Resolume.

## Conteúdo
- `index.html`: estrutura e textos do site.
- `styles.css`: visual responsivo.
- `script.js`: alternância PT/EN.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `resolume-plugins-lab`.
2. Envie os três arquivos (`index.html`, `styles.css`, `script.js`) e este README para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço ficará parecido com `https://SEU-USUARIO.github.io/resolume-plugins-lab/`.

## Antes de divulgar
- Confirme se o plugin já tem uma versão compilada e publicada em Releases.
- Atualize o link de download no `index.html` quando o arquivo estiver disponível.
- Confira a compatibilidade e os requisitos de cada plugin.
- Substitua ou complemente o texto e imagens demonstrativas com capturas reais dos plugins.

## Observação
O projeto é um site estático. Não coleta dados, não possui login e não inclui anúncios.
